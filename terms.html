1. About the service

QuoteTube ("the app") is Moament's internal Windows desktop tool. It uploads and schedules short videos produced by Moament to Moament's own YouTube channels using YouTube API Services, and prepares the same videos for Moament's TikTok account. It is not offered to the public.

2. YouTube API Services

  • QuoteTube uses YouTube API Services. Use of QuoteTube is subject to the YouTube Terms of Service.
  • YouTube data is handled under the Google Privacy Policy and our Privacy Policy.
  • Channel access is granted by the channel owner through Google OAuth 2.0 and can be revoked at any time at myaccount.google.com/permissions.

3. Content

  • Only content created by Moament or that Moament has the rights to use is uploaded.
  • Uploads comply with YouTube Community Guidelines and the TikTok Terms of Service.

4. TikTok

Videos sent to TikTok use the TikTok Content Posting API (inbox drafts). Access can be revoked in the TikTok app (Settings and privacy > Security > Apps and services).
